# Croftweaver

[Croftweaver](https://github.com/karero/croftweaver) is a free kit of skills that builds a
small-business website with your AI coding assistant. This plugin only points the way: it holds
one skill, which explains Croftweaver and gives you the install commands to type yourself. It
sends and stores nothing ([what it sends](https://github.com/karero/croftweaver#what-the-directory-plugin-sends)).

    claude plugin marketplace add https://github.com/karero/croftweaver.git
    claude plugin install croftweaver@croftweaver

Or, with Node 22.12 or newer, one line for the assistant you use:

    npm create croftweaver
    npm create croftweaver -- --codex
    npm create croftweaver -- --antigravity

The newest croftweaver.zip is at https://github.com/karero/croftweaver/releases/latest.
